# Quest Maxxing 🎀

A pastel-pink, bow-and-heart themed daily quest tracker. Check off your 27 daily quests, watch your progress bloom, and pick up where you left off during the day.

## Features
- 27 quests grouped into Morning Glow, Daytime Quests, and Evening Wind-down
- Daily progress bar and per-section counts
- Checkmarks saved in your browser for the current day
- One-tap reset for a fresh day
- Responsive layout with a pink gingham / kawaii stationery aesthetic

Open `index.html` in a browser or enable GitHub Pages for a hosted version.
